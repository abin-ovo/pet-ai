# 小团视觉与实现约定

参考：desktop-pet-concept.png。按已批准方案，以原创 SVG 小猫作为可动画角色。

- 主面板 440×640 逻辑像素，白色背景；桌面宠物为独立透明窗口。
- 主文字 #303d35，次文字 #7d837e，主绿 #647c68，分隔线 #e8ebe7。
- 小猫奶油色 #fff5e5、深棕描边 #725444、粉色耳朵与脸颊；小窝燕麦色，玩具鼠尾草绿。
- 系统中文无衬线字体，标题 24px、正文 14px、辅助文字 12px；按钮最小高度 38px。
- 顶栏小猫头像、宠物名、你的桌面小伙伴、关闭入口。四个 tab：陪伴、聊天、回忆、设置。
- 陪伴标题“今天，也一起慢慢来。”；关系描述根据实际状态，不能伪造相识天数。
- 空聊天：“这里，留给你慢慢说。”，未连接时明确提示并提供设置入口。
- 角色动画由纯状态机选择，SVG 与 CSS 提供同角色的明确动作变化，不使用静态 UI 截图充当可操作界面。
- 引导、设置与记忆界面沿用主面板控件，内容来自已批准方案。
