# macOS 资源采样记录

环境：Darwin 25.5.0 / arm64，Electron 44.9.0。每种状态 30 次、间隔 10 秒，约五分钟。通过 Electron app.getAppMetrics 汇总本应用进程树。CPU 数值沿用该 API 的百分比口径，内存为进程工作集之和，不等于去重后的系统物理占用。

| 状态 | CPU 中位数 | 工作集合计中位数 |
| --- | ---: | ---: |
| idle | 0.037% | 462.2 MiB |
| animated | 3.239% | 496.8 MiB |
| hidden | 1.795% | 428.4 MiB |

上述为隐藏动画修复前的首次采样。hidden 状态的 CPU 高于 idle，已追加原生动画暂停回归检查；修复后的 hidden 采样将单独记录。

未配置真实模型服务，真实聊天状态未采样。当前内存仍有优化空间，不能据此宣称低内存或双平台性能达标。Windows 尚无实机数据。

## 修复后补充采样

再次收集了 30 个样本，CPU 中位数 1.566%，工作集合计中位数 296.2 MiB。采样期间同时进行了原生 UI 检查，未逐样本保存窗口可见性，无法排除窗口被重新激活，因此这些数值仅作为初步记录，不视为严格的纯隐藏状态基准。

可靠的功能证据是新增原生回归：先确认面板有运行中的动画，隐藏后确认宠物和面板均无运行中的动画；该检查已通过。
